# Hussaini Production Studio

Comprehensive Hussaini audio production, poetic composition, Maqam and Tor architecture, AI studio prompt engineering (Flow Music, Suno, Udio), and DSP vocal montage engine.

## Installation

To add this skill to your workspace, run:

```bash
npx skills add husainalmualif/hussaini-production-studio
```

## Features

- **Poetic Composition**: Authored poetry across forms including Bahr Al-Nassari, Muwashah, Fayzi, Tajleeb, Abudhiyah, and Mawal.
- **Regional & Form-Specific Audio Production**: Studio prompt engineering for AI audio engines across Iraqi, Bahrani, Iranian, Bandari, and Ahwazi schools.
- **Audio Montage & DSP Processing**: Executable DSP tools for processing raw voice recordings with Latm, Dammam, Zanjeel, Ahaat, Dynacord echo, and spatial reverb.
